新建排行榜

运营在这里创建任务积分榜或赛事排行榜。左侧完成配置，右侧实时预览玩家端展示效果，确认无误后保存草稿或发布上线。

1. 选择榜单类型

不同类型会切换不同规则配置，发布后也会影响玩家端展示样式。

必填
日常游戏任务积分榜 玩家完成日常游戏任务获得积分，按周榜、月榜、年榜排名，适合拉动持续活跃。
赛事排行榜 按一段时间内的赛事成绩累计排名，展示云顶/无畏的参赛次数、冠军次数、前三次数、赛事积分和获奖情况。

2. 基础信息

配置榜单名称、展示时间、可见范围和展示端。

基础配置
赛事排行榜仅做累计战绩榜，不单独创建单场成绩单。

3. 任务积分规则

选择哪些日常任务计入榜单，并配置每个任务完成后获得的积分。

任务榜规则
计入榜单 任务名称 任务条件 完成积分 每日上限 说明
是 登录游戏账号 成功登录指定游戏账号 低门槛任务，拉起活跃
是 完成1局游戏 当日完成一局有效对战 主要积分来源
是 累计游戏时长 当日游戏时长 ≥ 60 分钟 适合门店提升上机时长
否 首次绑定账号 首次绑定游戏账号 可按活动需要开启

3. 赛事排名规则

配置累计战绩统计范围、榜单对象和名次积分换算，适合云顶个人榜和无畏队伍/玩家榜。

赛事榜规则
成绩 赛事积分 是否发奖 奖励内容 说明
冠军 是 无畏按队伍，队员继承冠军记录
亚军 是 展示在赛事战绩榜
季军 是 计入前三次数
完赛 否 用于鼓励持续参赛
