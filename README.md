# 产品原型发布中心

这个目录用于存放后续可外部访问的静态 HTML 原型页面。

## 当前页面

- `index.html`：外部总入口
- `tubang-scrm-design-ticket-workflow-business.html`：途邦 SCRM 设计工单业务演示页

## 后续新增页面流程

1. 把新的 HTML 文件放进这个目录。
2. 在 `index.html` 里新增一张页面卡片。
3. 提交到 GitHub 仓库。
4. GitHub Pages 会自动更新外部访问地址。

## 建议仓库名

`prototype-public-site`

## GitHub Pages 建议配置

- Source：Deploy from a branch
- Branch：`main`
- Folder：`/root`
